# MotionBOT

JavaScript/Node.js Discord bot with Discord utilities, moderation, fun commands, and Geometry Dash tools.

## Deploy

Use Node.js with:

- Build command: `npm install`
- Start command: `npm start`

Environment variables:

- `DISCORD_TOKEN` = your Discord bot token
- `CLIENT_ID` = your Discord application/client ID

Do not upload or commit your real `.env` file or bot token.

## Data

The bot stores its local JSON data in `motionbot-data.json`.
